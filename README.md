# Rabbit Data Analytics - Product Performance Dashboard

An interactive and modern Power BI dashboard designed for Rabbit Data Analytics. The project combines advanced data visualization techniques with a custom Apple-inspired Dark Mode UI to convert raw transactional data into actionable business insights.

## Key Features & Business Insights

* Executive KPIs: Real-time tracking of critical metrics including Total Sales ($252K), Total Profit ($9K), Quantities Sold (4.5K), and Profit Margins.
* Product Performance: Top-selling products identification and deep-dive analysis into sales and profitability.
* Category Breakdown: Interactive profit and revenue distribution across Technology, Office Supplies, and Furniture.
* Customer Matrix: Top 5 Customers tracking by sales volume and net profit.
* Quarterly Trends: Time-series line chart tracking overall sales movement over quarters.
* Dynamic Slicers: Interactive side menu allowing seamless filtering by Region, Category, and Customer Segment.

---

## Tools & Technologies Used

* Power BI Desktop: Core dashboard design, data modeling, and visual building.
* DAX (Data Analysis Expressions): Custom measures for dynamic calculations and conditional visual styling.
* HTML & CSS: Applied custom styling for rounded cards, custom headers, and seamless layout structure.
* Data Modeling: Star schema architecture for optimized report performance.
